## 🧠 Project Overview


This project provides the complete source code for a Mahjong game platform.


Supports multiple gameplay variants:


- Sichuan Mahjong
- Guangdong Mahjong
- 2-Player Mahjong


---


## 🎮 Features


- Real-time multiplayer matches
- Support for multiple game modes
- Robust game server architecture
- Scalable club system


---


## 🏆 Use Cases


- Mahjong game platforms
- Board & card game apps
- Game clubs
- Social entertainment systems

## ✨ Core Features


| Mahjong Type | Core Gameplay |
| :--- | :--- |
| 🀄️ **Sichuan Mahjong** | "Fight to the End" (Xue Zhan Dao Di), Missing Suit (Que Yi Men), Wind/Rain Bonuses, Ready-Hand Checks |
| 👥 **2-Player Mahjong** | Fast-paced 1v1, ideal for quick sessions |
| 🀄️ **Guangdong Mahjong** | Tui Dao Hu (Basic Scoring), Ji Ping, Red Dragon (Hong Zhong) Wildcard |
